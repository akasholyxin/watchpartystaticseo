## What you need

- **Desktop Chrome**
- **Access to the video** for each person: on subscription services, everyone uses their own account
- **Friends with the extension too**: they install it the same way, then join with your room code

## After you install

1. **Open the video** you want to watch, on any site with a standard video player.
2. **Click the {{brand}} icon.** The side panel opens on the right.
3. **Press Create Watch Party** and send the room code to your friends.
4. **Press play.** Everyone stays in sync. Start the video call from the panel to see each other.

The [full walkthrough](/how-it-works/) shows every step for hosts and guests.

## Privacy, in short

{{brand}} syncs a timestamp and a play or pause state, never your video. Calls go directly between participants, and you can use it as a guest without any personal information. Read the [privacy policy](/privacy/).

## Install not working?

- Make sure you're in **desktop Chrome**, not another browser or the mobile app
- If your Chrome is **managed by work or school**, an administrator may block extensions
- After installing, **refresh any video page** that was already open
